## Diagnosis
The hosted basemap and application-drawn location pins/labels come from separate renderers. The current code uses a 256 px world model, but Geoapify's Static Maps reference does not state whether that is the correct zoom scale for the endpoint. A test hard-coded to 512 px only validated that assumption and was removed. Reproduce the reported offset with an affected PDF/map image and the request venue/hotel coordinates; then compare visible basemap features or provider-native geometry against the same coordinates before selecting the fix.
